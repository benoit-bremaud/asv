# Security policy

## Supported versions

asv is in its conception phase and has no release yet. Reports apply to the `main` branch.

## Reporting a vulnerability

Do not open a public issue. Report privately through
[GitHub Security Advisories](https://github.com/benoit-bremaud/asv/security/advisories/new).

Please include the affected file or feature, the impact and steps to reproduce. You will get an
acknowledgement within 7 days. Fixes are disclosed once merged to `main`.

Reports involving personal data are handled under the project's GDPR rules
(`docs/architecture/security-and-rgpd.md`).
