# asv

> âge ? sexe ? ville ?

A retro web chat in the spirit of Caramail (1997–2005). Pick a pseudo, no photo, join a room,
chat about anything, and open a private conversation with a stranger.

## Status

Conception phase, nothing is built yet. See [docs/architecture](docs/architecture/README.md) and the
[Caramail research](docs/research/caramail.md).

## Planned (V1)

- Pink, blue and grey pseudos.
- Themed, regional and user-created rooms.
- Private messages in their own little window.
- Ignore button always one click away.
- 18+ only.
